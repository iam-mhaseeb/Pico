## System scenarios

- [ ] Dark mode
- [ ] Light mode
- [ ] Multiple monitors (Ask opens on active display)
- [ ] Unplug display (mascot moves to primary)
- [ ] Sleep / wake (hotkeys still work)
- [ ] Launch at login
- [ ] Accessibility off → permission UI
- [ ] Apple Intelligence off → friendly error
- [ ] Clipboard restore after text insert (including when pasteboard had an image)
- [ ] Pause Pico disables hotkeys and hides mascot
- [ ] Idle CPU near zero with mascot visible
